# Smart Food Donation Platform

A smart full-stack platform that connects food donors, NGOs, volunteers, and recipients to reduce food waste and improve food distribution.

## Planned Stack

- React + TypeScript + Vite
- Tailwind CSS
- Node.js + Express + TypeScript
- Firebase Authentication
- Firebase Firestore
- Firebase Storage
- Firebase Cloud Functions
- Google Maps Platform
- Firebase Hosting
